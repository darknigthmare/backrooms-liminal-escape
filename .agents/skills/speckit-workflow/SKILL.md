# Spec Kit workflow

Check AGENTS.md, existing specs, plans, tasks, decisions and `.ai-tools/README.md` first. If `.specify/` exists, inspect the installed scripts, commands, hooks and extensions before invoking any `speckit-*` skill. If `.specify/` does not exist, do not invoke nonexistent commands or silently initialize Spec Kit. Use ordinary spec/plan/tasks documents or propose optional setup from https://github.com/github/spec-kit when appropriate and authorized. Preserve project-specific commands; this file is workflow guidance, **not** a CLI installation.
